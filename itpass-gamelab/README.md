# ITパス ゲームラボ

ITパスポート試験の用語を、ゲーム感覚で覚えられる学習サイトです。
ログイン不要で、スマホでもPCでも遊べます。

## 遊び方（すぐに試す）

フォルダの中の `index.html` をダブルクリックすると、ブラウザで開きます。
サーバーやインストールは不要です。

## 試験の版（モード）の切り替え

ホーム画面の「試験の版を選ぶ」で切り替えます。
選んだ版はブラウザに記憶されます。
今どちらの版かは、画面右上に表示されます。

| | 今年度版 | 次年度以降版 |
|---|---|---|
| 対象 | 2026年度の試験（2027年3月まで） | 2027年度からの新試験（120分・100問） |
| 根拠 | シラバス Ver.6.4 | シラバス案 Ver.0.1（2026年8月 IPA公表） |
| 分野 | ストラテジ／マネジメント／テクノロジ | ビジネス／テクノロジ／セキュリティ・倫理 |
| 用語数 | 480語 | 594語（うち新シラバス用語114語に「NEW」表示） |

- 次年度以降版はシラバス**案**にもとづいています。正式版が公表されたら、内容を見直してください。
- 新しい3分野のうち、どの分野に用語を入れるかは、シラバス案の大分類の構成から判断しました。
  - ビジネス：ビジネス変革、データ・AIの利活用、組織活動
  - テクノロジ：デジタル技術、システム開発
  - セキュリティ・倫理：セキュリティ、倫理・コンプライアンス
- 学習記録（習得度・復習リスト）は、両方の版で共通です。
  ベストスコアは、仕分けレースとヒントクイズだけ版ごとに記録します。
- 計算問題（90問）は、両方の版で同じものを出題します。

## 収録ゲーム

| ゲーム | 内容 |
|---|---|
| 🃏 スワイプ用語カード | 知っている用語は右に、知らない用語は左にスワイプします。タップすると意味が表示されます |
| 🧠 神経衰弱マッチング | 「用語」と「意味」のペアをそろえます。難易度は3段階です |
| 📦 3分野仕分けレース | 60秒間で、用語を試験の3分野に仕分けます。分野は版によって変わります |
| 🔍 ヒント開示クイズ | ヒント1つで正解すると30点、2つで20点、3つで10点の4択クイズです。不正解の選択肢には、同じ種類の用語（攻撃なら攻撃、法律なら法律）を優先して出します |
| 🧮 計算ミニゲーム | 基数、稼働率、損益・財務、データ量などの計算問題です。解説付きです |
| 📖 用語辞典 | すべての用語を検索・絞り込みできます。分野、新シラバス用語、覚えた度合いで絞り込めます |

共通の機能

- **分野別の進捗ゲージ**：2回以上正解した用語を「習得済み」として数えます。
- **復習リスト**：どのゲームでも、間違えた用語や問題が自動でたまります。正解するとリストから消えます。

## 公開する方法（受講者に配る）

フォルダの中身をそのままWebサーバーにアップロードすれば公開できます。
無料で使える例は次のとおりです。

- **Netlify Drop**（https://app.netlify.com/drop）：フォルダをドラッグ&ドロップするだけで公開できます。
- **GitHub Pages**：リポジトリにアップロードし、設定から Pages を有効にします。

学習記録は受講者それぞれのブラウザ（localStorage）に保存されます。
先生が受講者の記録を見る機能はありません。

## 用語・問題を追加・修正する

テキストエディタで次のファイルを編集します。

| ファイル | 内容 |
|---|---|
| `data/terms.js` | 両方の版で使う用語。分野は今年度版のもの（S／M／T）を書きます |
| `data/terms-next.js` | 次年度以降版の設定。分野の振り分け（`NEXT_OVERRIDES`）と、次年度以降版だけの新用語（`TERMS_NEXT_ADD`）を書きます |
| `data/calc.js` | 計算問題 |

用語は次のような1行で追加します。

```js
{ term: "用語名", cat: "T", desc: "意味の説明", hints: ["ぼんやりしたヒント", "具体的なヒント"] },
```

- `cat` に書く記号
  - `data/terms.js`：`"S"`（ストラテジ）、`"M"`（マネジメント）、`"T"`（テクノロジ）
  - `TERMS_NEXT_ADD`：`"B"`（ビジネス）、`"T"`（テクノロジ）、`"E"`（セキュリティ・倫理）
- `data/terms.js` に足した用語は、次年度以降版では自動的に振り分けられます。
  - S と M はビジネス、T はテクノロジになります。
  - 別の分野に入れたいときは、`data/terms-next.js` の `NEXT_OVERRIDES` に用語名を追加します。
- `desc` と `hints` には、用語そのものを書かないでください。答えがわかってしまいます。
- 行末のカンマ `,` を忘れると動かなくなります。

## ファイル構成

```
index.html            … 入口
css/style.css         … デザイン（色は先頭の変数で変更できます）
data/terms.js         … 用語データ（480語・シラバスVer.6.4準拠）
data/terms-next.js    … 次年度以降版の分野振り分けと新用語（114語）
data/calc.js          … 計算問題データ（90問）
js/core.js            … 試験の版の切り替え・学習記録の保存・共通処理
js/app.js             … 画面切り替え・ホーム画面
js/games/*.js         … 各ゲーム・復習リスト・用語辞典
```

フォントは Google Fonts（M PLUS Rounded 1c）を読み込みます。
オフラインのときは、端末に入っている標準のフォントで表示されます。
